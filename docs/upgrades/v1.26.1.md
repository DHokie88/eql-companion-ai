# EQ Oracle desktop: upstream v1.26.1 integration

Integrated locally on 2026-10-19 from [EQ-Zera v1.26.1](https://github.com/Zeratfule/EQ-Zera/releases/tag/v1.26.1), commit `780c7afb3fe71f65db2cd8ae9d8c191b8ecc9db4`. Oracle's preceding commit was `275d069b3d458877bbefc4554ca2d70c5ec28fb3`; the previous upstream baseline was v1.26.0 (`b95051bf5eb24dca10f1a505233d60e8b863c2c4`).

## Included desktop changes

- Refreshed item, mob, quest, supplementary wiki spell, respawn, crawl-roster, and Plane of Sky data and associated wiki images.
- Recognized ordinary wiki item links in mob loot lists, using the known-item corpus to avoid treating unrelated links as drops. Live lookups and scraper paths use the same interpretation.
- Corrected secondary-slot shield parsing and bounded planner normalization for the `RND` class typo and stray slot wording.
- Rejoined respawn records whose wiki titles contain name qualifiers, including the ghoul lord.
- Updated Sky reward/drop associations and removed retired named NPCs from crawl requirements.
- Kept the upstream scraping improvements, release notes, and regression fixtures needed to maintain these desktop datasets.

## Fork compatibility and scope

Andrew chose **desktop only**. The separate native mobile project, its CI/configuration/documentation additions, and promotional website changes were excluded. Existing desktop phone-link behavior was not expanded into native mobile support.

Oracle's branding, icon assets, launcher, settings paths, custom Spells implementation, modifier/instrument calculations, and disabled telemetry/updater configuration were preserved. Exact focus-name resolution and numeric-ID catalog identity were reviewed against the changed item parsers. No game files, user profiles, inventory exports, or live combat state were edited. The matching Windows engine was built from source rather than reusing an upstream release binary.
